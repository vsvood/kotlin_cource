# Weatherator

## 📌 Описание
Консольное приложение для получения и анализа данных о температуре воздуха с использованием публичного API open-meteo.com. Позволяет получать температурные данные по заданным координатам и датам, находить экстремальные значения температуры.

## 🚀 Использование

### Требования
- Java 21+
- Gradle 8.0+

### Запуск приложения
1. Клонируйте репозиторий
2. Выполните в терминале:
```bash
./gradlew run
```

### Инструкция по работе
1. При запуске программа запросит:
    - Широту и долготу (например: `55.75 37.61`)
    - Начальную и конечную даты в формате ГГГГ-ММ-ДД (например: `2024-01-01 2024-01-07`)

2. После ввода данных программа:
    - Загрузит данные с API open-meteo
    - Проанализирует температурные показатели
    - Выведет минимальную и максимальную температуру с указанием времени

### Пример работы
```
Программа анализа исторических температурных данных
Введите широту и долготу через пробел (например, 55.75 37.61): 52.52 13.41
Введите начальную дату в формате ГГГГ-ММ-ДД: 2024-04-01
Введите конечную дату в формате ГГГГ-ММ-ДД: 2024-04-07
Загрузка данных с API...
Минимальная температура: 5.8°C, время: 2024-04-01T03:00
Максимальная температура: 18.2°C, время: 2024-04-03T15:00
```

## 🏗 Архитектура решения

### Основные компоненты
1. **UserInputHandler** - обработка пользовательского ввода:
    - Валидация координат (-90...+90 для широты, -180...+180 для долготы)
    - Проверка формата и корректности дат

2. **WeatherApiClient** - работа с API:
    - Отправка запросов к open-meteo.com
    - Параметризация запроса (координаты, даты)
    - Обработка ответа

3. **TemperatureAnalyzer** - анализ данных:
    - Поиск минимальной и максимальной температуры
    - Фильтрация null-значений
    - Определение времени экстремальных значений

### Особенности реализации
- Использование Ktor для HTTP-запросов
- Kotlinx.serialization для работы с JSON
- Корутины для асинхронных операций
- Обработка ошибок ввода и сетевых ошибок
- Конфигурируемый JSON-парсер с обработкой null-значений

### Опциональные возможности
- Кэширование запросов в памяти
- Возможность расширения для анализа других метеопараметров
